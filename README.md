# Mission Design Game: Tools

Two small static web pages for our board and card game, made for the NASA Space Apps Challenge 2026 (challenge "Space Mission Design Game").

- `mission-planner.html`: calculator for mass, cost, power, thrust-to-weight ratio, delta-v, data and score multiplier. Formulas follow the [NASA Glenn Research Center: Ideal Rocket Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/ideal-rocket-equation/).
- `asteroid-risk.html`: danger meter for the asteroid mission.
- `index.html`: start page linking both.

**Use of AI:** The code was generated with AI assistance (Claude by Anthropic) following the team's specifications. The game concept, rules and values come from the team. All numbers in the pages are placeholders until playtesting. The pages use no external libraries or images.
